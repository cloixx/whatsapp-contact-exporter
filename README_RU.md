Локальная утилита для экспорта собственных контактов WhatsApp (включая контакты, сохранённые только внутри учётной записи WhatsApp) в форматы **Google Contacts CSV**, **vCard 3.0 (.vcf)** и **CSV для Excel**.

Работает автономно на вашем компьютере. Без облачных сервисов, root-прав и платных подписок.

## 💡 Зачем создан этот проект

Каждый, кто хоть раз пытался перенести контакты из WhatsApp в Google Contacts или на новый смартфон, сталкивался с неприятным сюрпризом: сотни номеров сохранены только в облаке WhatsApp и не экспортируются стандартными средствами. Мы сами прошли через это! 😅

Этот проект создан для людей, которым нужно быстро, бесплатно и безопасно забрать свои контакты.

## 🌟 Основные преимущества

- **Экспорт облачных контактов WhatsApp**: Находит контакты, созданные непосредственно в WhatsApp и отсутствующие в записной книжке телефона.
- **Контакты из диалогов**: Извлекает участников из истории активных личных чатов.
- **Фильтрация шума**: Автоматически исключает группы (`@g.us`), рассылки (`@broadcast`), каналы (`@newsletter`) и сервисные аккаунты.
- **Поддержка WhatsApp LID**: Сопоставляет идентификаторы Linked Identity Device (`@lid`) с реальными телефонными номерами. Нераспознанные LID сохраняются в `unresolved_contacts.csv`.
- **Международный формат E.164**: Приведение номеров к стандарту (`+380...`, `+1...`, `+49...`).
- **Умная дедупликация**: Объединяет повторяющиеся записи, отдавая приоритет сохранённым именам.
- **Поддержка кириллицы (UTF-8 BOM)**: Таблицы открываются в Excel, LibreOffice и Google Таблицах без искажения шрифтов.
- **100% локально и безопасно**: Работает исключительно в режиме чтения, без отправки сообщений и передачи данных наружу.

## 🚀 Пошаговое руководство

### 🪟 Windows (Простой запуск)
1. Установите [Node.js (LTS)](https://nodejs.org/) со стандартными параметрами.
2. Скачайте проект (зелёная кнопка **Code** -> **Download ZIP**) и распакуйте архив в папку.
3. Дважды кликните по файлу **`run.bat`**.
4. Отсканируйте появившийся QR-код через мобильное приложение WhatsApp.
5. Готовые файлы будут сформированы в папке **`output`**.

### 🍏 macOS
1. Установите Node.js (с [nodejs.org](https://nodejs.org/) или через `brew install node`).
2. В терминале выполните:
   ```bash
   ./run.sh
   ```
3. Отсканируйте QR-код смартфоном.

### 🐧 Linux (Ubuntu, Debian, Fedora, Arch)
1. Установите Node.js и Chromium:
   ```bash
   sudo apt update && sudo apt install nodejs npm chromium-browser
   ```
2. Запустите:
   ```bash
   chmod +x run.sh
   ./run.sh
   ```

### ❄️ NixOS
Запуск в изолированном окружении Nix Flake:
```bash
./run.sh
```

## 📱 Как авторизоваться через QR-код

1. Запустите `./run.sh` или `run.bat`.
2. Откройте **WhatsApp** на смартфоне.
3. Перейдите: **Меню** (три точки) -> **Связанные устройства** -> **Привязать устройство**.
4. Наведите камеру на QR-код в окне терминала.
5. Утилита дождётся синхронизации базы, сохранит файлы в папку `./output/` и закроет браузерную сессию.

---

## 📥 Как импортировать контакты в Google Contacts

1. Откройте [Google Contacts](https://contacts.google.com/).
2. В левой колонке нажмите **Импортировать** (**Import**).
3. Нажмите **Выбрать файл** и укажите: `output/google_contacts_import.csv`.
4. Нажмите **Импортировать**. Контакты сразу появятся на вашем Android-устройстве или в учётной записи Google.
