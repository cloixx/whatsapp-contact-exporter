Локальна утиліта для експорту власних контактів WhatsApp (зокрема тих, що збережені виключно в обліковому записі WhatsApp) у формати **Google Contacts CSV**, **vCard 3.0 (.vcf)** та **CSV для Excel**.

Працює автономно на вашому комп'ютері. Жодних хмарних сервісів, рут-прав чи платних підписок.

---

## 💡 Чому створено цей проект

Кожен, хто намагався перенести контакти з WhatsApp до Google Contacts чи нового смартфона, зустрічався з проблемою: сотні номерів зберігаються виключно в хмарі WhatsApp і не експортуються стандартними шляхами. Ми самі зіткнулися з цим! 😅

Проект створено для зручності людей, яким потрібно легко, безпечно та безкоштовно зберегти свою адресну книгу.

## 🌟 Основні можливості

- **Експорт хмарних контактів WhatsApp**: Знаходить контакти, створені безпосередньо у WhatsApp, яких немає у телефонній книзі смартфона.
- **Діалоги з чатів**: Збирає контакти зі списку активних особистих листувань.
- **Фільтрація зайвого**: Автоматично відсікає групові чати (`@g.us`), розсилки (`@broadcast`), канали (`@newsletter`) та службові номери.
- **Обробка WhatsApp LID**: Перетворює ідентифікатори Linked Identity Device (`@lid`) у справжні номери телефонів або безпечно зберігає невідомі в `unresolved_contacts.csv`.
- **Міжнародний формат E.164**: Нормалізація номерів (`+380...`, `+1...`, `+49...`).
- **Розумна дедуплікація**: Об'єднує однакові номери, надаючи перевагу повним збереженим іменам.
- **Підтримка кирилиці (UTF-8 BOM)**: Коректне відкриття файлів в Excel, LibreOffice та Google Sheets без спотворення символів.
- **Повна конфіденційність**: Працює в режимі читання без відправки повідомлень чи передачі даних на сторонні сервери.

## 🚀 Детальна покрокова інструкція зі встановлення (для кожної ОС)

### 🪟 Windows (Проста інструкція для початківців)

#### Крок 1: Встановлення Node.js та браузера
- **Браузер**: Переконайтеся, що на комп'ютері встановлено **Google Chrome** або **Microsoft Edge** (утиліта використовує браузер у фоновому режимі для відкриття WhatsApp Web).
- **Node.js**: Перейдіть на офіційний сайт [nodejs.org](https://nodejs.org/) і завантажте версію **LTS** (рекомендована для більшості).
  - Запустіть завантажений інсталятор (`.msi`).
  - У всіх вікнах натискайте **Next** (Далі), прийміть ліцензійну угоду та натисніть **Install**. Жодних спеціальних налаштувань змінювати не потрібно!
  - *(Перевірка)*: Відкрийте командний рядок або PowerShell та введіть `node -v` — відобразиться версія (наприклад, `v20.x` чи `v22.x`).

#### Крок 2: Завантаження проекту
- На сторінці репозиторію на GitHub вгорі праворуч натисніть зелену кнопку **Code**, після чого виберіть **Download ZIP**.
- Відкрийте завантажений архів і натисніть **Видобути все...** (розпакуйте папку, наприклад, на Робочий стіл або в Завантаження).

#### Крок 3: Запуск в один клік
- Відкрийте розпаковану папку.
- Двічі клацніть лівою кнопкою миші на файл **`run.bat`**.
  - *Підказка*: Якщо Windows покаже синій екран захисту («Захисник Windows убезпечив ваш ПК...»), натисніть **Докладніше** (More info), а потім **Виконати за будь-яких умов** (Run anyway).
  - При першому запуску програма сама завантажить потрібні модулі (15–30 секунд).
  - Прямо в чорному вікні з'явиться текстовий QR-код для сканування!

### 🍏 macOS (Покроково для Mac)

#### Крок 1: Встановлення Node.js
- Завантажте та запустіть інсталятор (`.pkg`) з офіційного сайту [nodejs.org](https://nodejs.org/).
- *Або через Homebrew:*
  ```bash
  brew install node
  ```
- Переконайтеся, що у папці `/Applications` присутній Google Chrome.

#### Крок 2: Завантаження та розпакування
- Натисніть зелену кнопку **Code** -> **Download ZIP** на GitHub. Розпакуйте завантажений архів подвійним кліком.

#### Крок 3: Запуск через Термінал
- Відкрийте програму **Термінал** (натисніть `Cmd + Пробіл`, введіть `Термінал` та натисніть `Enter`).
- Перейдіть у папку з проектом (напишіть `cd ` і перетягніть розпаковану папку мишкою з Finder у вікно Терміналу):
  ```bash
  cd ~/Downloads/whatsapp-contact-exporter-main
  ```
- Надайте права на виконання та запустіть скрипт:
  ```bash
  chmod +x run.sh
  ./run.sh
  ```
- У Терміналі з'явиться QR-код для підключення!

### 🐧 Linux (Ubuntu, Linux Mint, Debian, Fedora, Arch)

#### Крок 1: Встановлення необхідних пакунків
Відкрийте термінал і встановіть Node.js та Chromium:

- **Ubuntu / Linux Mint / Debian**:
  ```bash
  sudo apt update
  sudo apt install -y nodejs npm chromium-browser git
  ```
- **Fedora / RHEL**:
  ```bash
  sudo dnf install -y nodejs npm chromium git
  ```
- **Arch Linux / Manjaro**:
  ```bash
  sudo pacman -S --needed nodejs npm chromium git
  ```

#### Крок 2: Клонування або завантаження
```bash
git clone https://github.com/cloixx/whatsapp-contact-exporter.git
cd whatsapp-contact-exporter
```

#### Крок 3: Запуск
```bash
chmod +x run.sh
./run.sh
```
*Скрипт перевірить систему, автоматично виконає `npm install` за потреби, підключиться до системного Chromium і виведе QR-код.*

## 📱 Авторизація через QR-код

1. Запустіть `./run.sh` або `run.bat`.
2. Відкрийте **WhatsApp** на телефоні.
3. Перейдіть: **Меню** (три крапки) -> **Пов'язані пристрої** -> **Прив'язати пристрій**.
4. Наведіть камеру на QR-код у терміналі.
5. Програма дочекається синхронізації адресних записів, сформує файли у папці `./output/` та коректно завершить роботу.

---

## 📥 Імпорт до Google Contacts

1. Перейдіть на сторінку [Google Contacts](https://contacts.google.com/).
2. У лівому меню натисніть **Імпортувати** (**Import**).
3. Виберіть файл: `output/google_contacts_import.csv`.
4. Натисніть **Імпортувати**. Контакти з'являться на вашому телефоні Google Pixel / Android.
